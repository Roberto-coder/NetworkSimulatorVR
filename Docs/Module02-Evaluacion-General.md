# Evaluación de conocimientos: infraestructura de red

Cuestionario común para los grupos de video/texto y realidad virtual. Selecciona una sola respuesta por pregunta. Cada acierto vale un punto; puntuación total de 0 a 10.

## 1. ¿Cuál es la función principal de un rack de comunicaciones?

- **A.** Asignar direcciones IP a los equipos.
- **B.** Alojar y organizar físicamente los equipos de infraestructura.
- **C.** Seleccionar la ruta de los paquetes entre redes.
- **D.** Filtrar las conexiones no autorizadas.

## 2. ¿Cuál es la función principal de un switch en una red local?

- **A.** Distribuir alimentación eléctrica a los equipos.
- **B.** Traducir nombres de dominio a direcciones IP.
- **C.** Conectar dispositivos y reenviar tramas hacia el puerto correspondiente.
- **D.** Asignar obligatoriamente una dirección IP a cada dispositivo.

## 3. ¿Para qué se utiliza un patch panel?

- **A.** Para terminar y organizar el cableado y facilitar su conexión a los equipos de red.
- **B.** Para decidir a qué dispositivo se envía cada trama Ethernet.
- **C.** Para asignar direcciones IP automáticamente.
- **D.** Para proporcionar energía de respaldo durante un apagón.

## 4. ¿Cuál es la función principal de una PDU dentro de un rack?

- **A.** Organizar las terminaciones de los cables de datos.
- **B.** Controlar el tráfico permitido entre redes.
- **C.** Mantener por sí sola los equipos encendidos durante un apagón.
- **D.** Distribuir alimentación eléctrica entre los equipos.

## 5. ¿Por qué es importante mantener libres las entradas y salidas de aire de los equipos?

- **A.** Para aumentar el número de puertos disponibles.
- **B.** Para favorecer la refrigeración y reducir el riesgo de sobrecalentamiento.
- **C.** Para evitar la necesidad de configurar la red.
- **D.** Para incrementar automáticamente la velocidad de los enlaces.

## 6. ¿Cuál es la principal ventaja de identificar los cables en ambos extremos?

- **A.** Aumentar la velocidad de transmisión del enlace.
- **B.** Evitar que sea necesario comprobar las conexiones.
- **C.** Reconocer su origen y destino durante el mantenimiento.
- **D.** Corregir automáticamente una conexión equivocada.

## 7. ¿Para qué sirve el puerto de consola de un switch administrable?

- **A.** Para acceder a su administración y configuración local.
- **B.** Para ampliar la cantidad de puertos Ethernet de usuario.
- **C.** Para distribuir alimentación a otros equipos del rack.
- **D.** Para sustituir el enlace que transporta el tráfico de los usuarios.

## 8. ¿Para qué se configura una dirección IP de gestión en un switch administrable?

- **A.** Para fijar la velocidad de todos sus puertos.
- **B.** Para reemplazar las direcciones MAC de los dispositivos conectados.
- **C.** Para asignar automáticamente direcciones IP a todos los usuarios.
- **D.** Para permitir su administración mediante la red, cuando existe conectividad.

## 9. ¿Qué función cumple la puerta de enlace predeterminada de un dispositivo IP?

- **A.** Indicar a qué equipo enviar el tráfico destinado a otras redes cuando no hay una ruta más específica.
- **B.** Identificar físicamente cada cable del rack.
- **C.** Determinar cuánta energía necesita el dispositivo.
- **D.** Traducir todos los nombres de dominio de la red.

## 10. Si se cambia el destino de un cable, ¿qué debe hacerse con su identificación y documentación?

- **A.** Conservarlas siempre sin cambios para mantener el historial.
- **B.** Actualizarlas para que correspondan a la nueva conexión.
- **C.** Eliminar la identificación de todos los cables cercanos.
- **D.** Cambiar únicamente el nombre del rack.

## Aplicación a ambos grupos

Usar los mismos enunciados, opciones, tiempo disponible e instrucciones. Los dos materiales de aprendizaje deben cubrir estos contenidos. Aplicar la evaluación en el mismo formato para ambos grupos, por ejemplo en papel o en un formulario, evitando que solo uno de ellos deba responder dentro de VR. No mostrar respuestas correctas hasta terminar la evaluación.

Comparar la puntuación de 0 a 10. Si se aplica antes y después de la intervención, también se puede comparar el cambio de puntuación. Este cuestionario evalúa conocimientos; no mide por sí solo destreza práctica, usabilidad o efectividad global del proyecto. Es una propuesta de contenido, no un instrumento validado.
