# Imágenes del selector de cables

Generadas con la herramienta integrada imagegen. Son ilustraciones de producto, no diagramas de terminación ni referencias exactas de pines.

Archivos: `Assets/Art/CableCards/Cat5e.png`, `Cat6.png`, `Cat6A.png`, `Cat7.png`.
Cada archivo se importa como Sprite individual y se asigna en las opciones de CableSelectionPanel de Modulo1.

## Prompts utilizados

Para cada imagen se utilizó el siguiente prompt, sustituyendo SUBJECT por el asunto correspondiente:

> Use case: product-mockup. Create one square illustration for a Unity educational cable selection card. Subject: SUBJECT. Clean detailed 3D product illustration, single short curved cable and its connector, centered fully in frame, dark navy background #0e1f36, studio lighting, no text, no labels, no watermark. This is an illustrative product image not a wiring diagram.

- Cat5e: `Cat5e green UTP cable with RJ45 plug`
- Cat6: `Cat6 blue UTP cable with RJ45 plug`
- Cat6A: `Cat6A cyan shielded cable with metallic RJ45 plug`
- Cat7: `Cat7 purple S/FTP cable with TERA connector, not RJ45`

El contenido descriptivo de las tarjetas corresponde al texto proporcionado por el usuario.
